# ChannelShift 0.2.1

회원 작업실의 Linux 서버 배포와 HTML 산출물 검증 호환성을 보완한 패치입니다. 0.2.0의 자연어 요구사항·질문·답변, 단계별 제작·검수, 필수 운영 정보와 납품 ZIP 기능을 유지합니다.

## HTML 검증 일관성

Python 버전에 따라 HTML 파서가 잘못된 선언을 예외로 처리하거나 주석처럼 넘기는 차이를 발견했습니다. 프론트 산출물의 정책 링크·푸터 검증에서 해당 선언을 일관되게 거부하도록 수정했습니다. 정상 주석과 스크립트 안에 있는 예시 문자열은 선언으로 오인하지 않습니다. 생성된 페이지를 실제 실행하는 검사는 아닙니다.

## 회원 서버 배포

서버용 컨테이너·리버스 프록시·Cloudflare Tunnel 구성을 제공합니다. 회원 데이터와 서버 자격증명은 공개 배포 파일에서 분리하고, 프로세스 재시작·상태 확인 및 HTTPS 공개 origin 설정을 사용합니다. 실행 방법과 환경별 설정은 [회원 작업실 배포 안내](DEPLOYMENT.md)에 있습니다.

회원 작업실 자체의 서버 배포와, 작업실이 생성한 고객 사이트의 운영 배포는 별개입니다. 생성된 고객 앱은 계속 소스·검수 근거·정책 페이지를 ZIP으로 제공하며 실제 동작·보안 인수 검사와 운영 배포를 자동 완료하지 않습니다. 회원별 Codex 로그인은 각 회원이 진행해야 합니다. 공개 서버가 응답하는 것만으로 메일 발송이나 외부 처리 서비스 호출이 검증된 것은 아닙니다.

## 설치 파일

- `channelshift-0.2.1-py3-none-any.whl`: 프로그램·회원 서버·MCP 패키지.
- `channelshift-0.2.1.tar.gz`: 소스, 테스트, 문서와 라이선스.
- `channelshift-skill-0.2.1.zip`: Codex 스킬과 같은 버전의 wheel.
- `SHA256SUMS.txt`: 세 배포 파일의 SHA-256 확인값.

Python 3.10 이상이 필요합니다. 회원 DB, 고객 원문, 로그인 세션, API 토큰과 메일 비밀번호를 포함하지 않습니다. 0.2.0 배포 파일과 당시 검증 기록은 보존합니다.
