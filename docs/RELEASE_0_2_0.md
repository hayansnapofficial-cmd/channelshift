# ChannelShift 0.2.0

고객의 자연어 요구사항에서 시작하는 제작 작업실을 공개합니다. 회원 본인의 Codex 연결로 질문과 답변을 정리하고, 확인된 요구사양을 다음 단계의 입력으로 사용합니다.

## 달라진 제작 흐름

요구사항·답변 → 요구사양 확정 → 화면 설계 → ERD → API 계약 → SQLite 구축 검사 → 백엔드 → 프론트 → 검수·납품.

- 여섯 개 작업 구역으로 화면을 정리하고 계정·Codex·MCP 연결을 계정 패널에 모았습니다.
- 추가 요청은 원문을 보존한 채 새 기록으로 남깁니다. 상위 요구사양이나 산출물이 바뀌면 하위 검수를 다시 진행합니다.
- 각 단계에 작업자의 수정·검수 이유를 기록합니다. 이 기록은 고객 서명이나 법률 검토 완료를 뜻하지 않습니다.
- 화면 설계와 프론트의 HTML·CSS를 격리된 정적 미리보기로 확인할 수 있습니다. 미리보기에서는 스크립트와 외부 요청을 실행하지 않습니다.
- 회원별 데이터 격리, 오래된 탭의 저장 충돌 방지, 중단된 생성 작업의 복구를 지원합니다.

## 반드시 포함되는 사이트 운영 정보

판매페이지·서비스페이지·SaaS 프로젝트에 사업자정보, 개인정보처리방침, 통신판매업정보, 고객문의, 호스팅사, 서비스 이용약관, 취소·환불 규정을 제품의 필수 납품 항목으로 적용했습니다.

미작성 상태에서는 초안을 저장할 수 있지만 납품 파일을 만들 수 없습니다. 작성한 정보는 사이트 하단과 정책 페이지에 포함됩니다. 실제 사업자 정보와 정책은 운영자가 입력해야 하며, 작성 완료 여부가 법적 적합성이나 사실성을 보증하지는 않습니다.

## 이번 배포의 실행 범위

첫 출력 형식은 Python 표준 라이브러리 + SQLite + HTML/CSS/JavaScript입니다. 검증된 ERD에서 생성한 DDL을 별도 메모리 DB에서 실제 검사합니다. 생성된 백엔드·프론트는 구문·계약 구조를 검사하고, 검수한 소스·운영 정책·검사 근거·실행 안내를 ZIP으로 제공합니다.

**생성된 애플리케이션의 실제 동작·보안 인수 검사와 운영 서버 배포는 자동 완료하지 않습니다.** 서버 연결, 회원 메일, Codex 인증 및 공용 서비스 연결도 설치 환경별 설정이 필요합니다. 이 GitHub 배포는 설치 가능한 프로그램·스킬·MCP 배포이며, 공개 회원 사이트가 운영 중이라는 의미는 아닙니다.

## 설치 파일

- `channelshift-0.2.0-py3-none-any.whl`: 프로그램과 MCP Python 패키지.
- `channelshift-0.2.0.tar.gz`: 원본 소스, 테스트, 설치 스크립트, 문서와 라이선스.
- `channelshift-skill-0.2.0.zip`: Codex 스킬과 설치용 wheel.
- `SHA256SUMS.txt`: 위 세 파일의 SHA-256 확인값.

Python 3.10 이상에서 배포 wheel을 설치합니다. 패키지 의존성 설치에는 인터넷 연결이 필요합니다.

```console
python -m pip install channelshift-0.2.0-py3-none-any.whl
channelshift-studio
```

회원 기능은 `channelshift-members --port 5189`, MCP는 `channelshift-mcp`로 시작합니다. 회원 서버를 공개하는 방법과 선행 설정은 소스 배포의 `docs/DEPLOYMENT.md` 및 `docs/MEMBER_AUTH.md`를 확인하세요. 기존 가상환경을 보존하는 Windows·스킬 설치기의 동작은 유지했습니다. 이미 설치된 환경의 업그레이드는 별도 환경에서 먼저 검증하는 편이 좋습니다.

## 검증과 배포 자료의 경계

제작 작업실은 합성 회원·모델 응답으로 단계 흐름, 회원 격리, 필수 항목, ZIP 포함 자료와 정적 미리보기를 검증했습니다. 실제 유료 Codex 생성 호출이나 생성된 사이트의 공개 운영 검증을 대신하지 않습니다. 배포 과정에서 최종 테스트 결과를 별도로 확인합니다.

배포 파일에는 회원 DB, 프로젝트 원문, 로그인 세션, 메일 비밀번호, API 토큰을 포함하지 않습니다. 패키지 생성 시 비공개 상태 경로·데이터베이스·아카이브 링크를 거부하고 작업실에 필요한 정적 파일의 포함을 검사합니다. 오픈소스 라이선스 고지는 유지합니다.
